AI APPAREL GROUP · CRM FILE UPDATE

Add “Resend Setup Email” and fix password reset

This utility modifies your current crm/index.html in your browser and downloads the complete updated file. It does not upload anything or send an email.

1. Choose the current live CRM file

In GitHub, open crm/index.html, choose Download raw file, then select it here.

2. Generate the updated full file

The update adds a branded Resend Setup Email button beside each employee. It requests a password recovery email for the existing employee and redirects to the password setup flow; it never creates a duplicate account.
